# Distance Review UI Handoff

This historical handoff has been superseded by the implemented
[Reference-Based Distance Annotation](./reference-based-distance-annotation.md)
workflow. Use that document for layout, timing, navigation, confirmation, infant
relationships, and completion semantics; do not implement the earlier proposals
or treat their historical test counts as current validation.

The desktop design still follows the [original mockup](./images/distance-mockup.jpg):
filters on the left, aligned animal/reference images in the center, and
individual/sample controls on the right. Ordinary Review and Distance remain
independent. Mobile layout and further redesign are deferred.

For architecture/migration cleanup, recovery, and current validation evidence,
see the [cleanup execution plan](./distance-branch-cleanup-plan.md).
